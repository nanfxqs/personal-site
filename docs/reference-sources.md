# Reference Sources (参考源清单)

本文件记录各学科在编写 **Topic（知识点）** 和设计交互可视化时可借鉴的优质参考源。当 AI Agent 增量写入知识点时，应优先参考对应学科的权威教材与下述高质量可视化/讲解站点，并在 Topic 元数据的 `sources` 字段中注明来源。

## 408（计算机学科专业基础）

### 数据结构 (DS)
- **Hello 算法**：https://www.hello-algo.com/ — 动画图解清晰、代码风格统一、分步讲解极佳，可借鉴其交互演示结构与视觉表达。
- **VisuAlgo**：https://visualgo.net/ — 树、图、排序等算法的分步状态可视化参考。
- **经典教材**：严蔚敏《数据结构（C语言版）》；王道《数据结构考研复习指导》。

### 计算机组成原理 (CO)
- **经典教材**：唐朔飞《计算机组成原理》、袁春风《计算机系统基础》；王道《计算机组成原理考研复习指导》。
- **交互参考**：CPU 流水线、Cache 映射、IEEE 754 浮点数转换交互可视化器。

### 操作系统 (OS)
- **OSTEP (Operating Systems: Three Easy Pieces)**：https://pages.cs.wisc.edu/~remzi/OSTEP/ — 并发、虚拟内存、文件系统的直观类比与原理剖析。
- **经典教材**：汤小丹《计算机操作系统》；王道《操作系统考研复习指导》。

### 计算机网络 (CN)
- **Protocol Explorer**：https://protocol-explorer-alpha.vercel.app/ — 协议帧/报文结构与交互式分层解析的优秀设计参考。
- **经典教材**：谢希仁《计算机网络（第8版）》、《计算机网络：自顶向下方法》（Kurose & Ross）；王道《计算机网络考研复习指导》。

## 数学一 (Math I)

- **3Blue1Brown（《微积分的本质》《线性代数的本质》）**：https://www.3blue1brown.com/ — 几何直觉与 2D/3D 动态变换的黄金参考。
- **Seeing Theory**：https://seeing-theory.brown.edu/ — 概率论与数理统计的交互式可视化标杆。
- **经典教材**：同济《高等数学》、同济《线性代数》、浙大《概率论与数理统计》。

# The Lookback · Surf 动效研究

## 一手证据

- **设计意图**：Surf 是 Better Off® Studio 创意档案的浏览视图之一。Gil Huybrecht 与 Jesper Landberg 为喜欢冲浪的 Keith 加入这一视图，让档案图片呈现海浪般的运动。[官方 Surf](https://tlb.betteroff.studio/surf/) · [创作者案例，2026-03-03][case]
- **滚动与透视**：图片在 CSS 3D 空间里旋转、按透视叠放。滚动速度影响浪形的强弱，向任一方向都能循环浏览。[创作者案例][case]
- **悬停**：指针下的图片像书从书架中探出。创作者指出，滚动时图片会不断经过指针，缩放或淡化其他图片的效果会频繁触发。[创作者案例][case]
- **跨视图转场**：自定义 FLIP 在切换路由前记录图片边界，切换后按内容 ID 配对，只对两侧视口均可见的图片用 GSAP 补间位置与缩放。涉及 Surf 时，匹配边界还需计入已有的 3D 变换。[创作者案例][case]

## 推断与未知

滚动速度影响浪形强弱，意味着到达同一浏览位置时，快滚和慢滚可能呈现不同的画面。案例未给出速度到变换的映射、缓动参数或循环接缝算法，具体公式与数值仍待验证。[推断依据][case]

## 原站观察与项目实现

在 Chromium 打开原站并选择无声进入，再切换到 Surf。静止时，画面里的图像底缘从左下向右上抬升。右侧图像更宽，左侧有接近侧面的薄片。图像的高度和宽高比各不相同，彼此局部遮挡。日常页用共享 CSS 透视、连续环形坐标和速度相关的高度偏移实现这类运动。文章标题与日期置于画面下方，方便阅读和打开文章。

## 作者首页的拖动表现

在 1440 × 900 的 Chromium 视口记录了静止、按住横拖和松手后三个状态。首页是一条近似等高的横向画廊，封面的上下边缘会弯曲，图片内部也随曲面变形。慢拖后停住再松手时，画廊停留在两张封面之间，位移很小。[作者首页](https://jesperlandberg.com/)

### 公开构建产物核对

- 首页路由的横向轮播维护目标位移和显示位移两个值。输入增量先进入目标值，显示值每帧只走剩余距离的一部分。桌面目标差超过一屏时会被软限制。渲染层收到的是位移差，变量虽标为速度，实际单位仍是像素。[首页路由模块][home-chunk]
- 鼠标沿主轴移动超过 10 像素才开始拖动。原站把拖动增量乘以 1.5，松手时仅在最近一次移动距松手不足 100 毫秒的情况下追加位移，附加量与最后一笔增量有关。滚轮有独立的输入调度，触屏也走不同路径。[输入模块][input-chunk] · [入口模块][core-chunk]
- WebGL 层把 DOM 卡片位置映射到场景。曲面按全视口的横坐标计算，桌面的静态形状是有衰减尾部的 S 形深度场。位移差经软限幅后调整深度和扭转。公开入口还包含曲面法线着色、地面反射、按可见性调度的视频纹理及粒子等效果。[入口模块][core-chunk]

### 日常页调整

用已有的 Three.js 渲染共享曲面，改用目标与显示位移差驱动深度和扭转。拖动增量进入目标值，显示位置用按时间归一化的阻尼追随。松手只在有近期输入时追加位移，静止后无需持续绘制。原站的实时视频预览、地面反射和跨页面转场属于其作品集表现层，当前日常页使用文章静态封面与原有页面导航。

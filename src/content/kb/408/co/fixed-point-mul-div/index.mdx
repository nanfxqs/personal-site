## 核心直觉与三寄存器硬件模型

在串联式定点数运算器中，CPU 不直接用组合逻辑展开整张乘法表（并行阵列方案见 <TopicLink id="408/co/alu-and-carry-lookahead" />），而是复用同一个 **加法器（ALU）** 与 **移位器**，通过 **“判断 → 加减 → 移位”** 的迭代循环完成乘除运算。

无论原码还是补码，硬件都围绕以下三个核心寄存器协作（基础编码与溢出规则见 <TopicLink id="408/co/fixed-point-and-complement" />）：

| 寄存器 | 乘法中的职责 | 除法中的职责 |
| :--- | :--- | :--- |
| **`X`（通用/锁存）** | 存放被乘数 $x$ | 存放除数 $y$ |
| **`ACC`（累加器）** | 存放部分积高位（初值清 $0$） | 存放被除数 / 中间余数 |
| **`MQ`（乘商寄存器）** | 初始存放乘数 $y$；随右移逐步接纳低位乘积 | 初始可存低位被除数；随左移逐位写入商 |

> **408 高频易错点**：
> 1. **右移方向与类型**：原码一位乘使用**逻辑右移**（高位补 $0$）；补码 Booth 乘法必须使用**算术右移**（高位补符号位）。
> 2. **双符号位作用**：部分积在中间相加时可能短暂超出 $1$，使用双符号位（如 `00` / `11`）即可暂存进位而不丢符号，右移一步后自动恢复合法范围。

## 高频核心一：原码一位乘法

**核心思想**：**符号位与数值位分离**。乘积符号由两操作数符号异或决定（$P_f = x_f \oplus y_f$），数值位直接取绝对值 $|x| \times |y|$ 计算。

设数值位长度为 $n$：
1. `ACC` 置 $0$，`MQ` 存入 $|y|$；
2. 重复 $n$ 轮：**判断 `MQ` 最低位**——若为 `1` 则 `ACC ← ACC + |x|`，若为 `0` 则 `+ 0`；
3. 随后 `ACC` 与 `MQ` **联合逻辑右移 1 位**；
4. 最终 `ACC`（数值位）与 `MQ` 拼接为 $2n$ 位数值乘积，再拼上符号位 $P_f$。

> **408 选择题考点**：n 位数值位需要执行 **$n$ 次右移**，最多 **$n$ 次加法**（实际加法次数等于 $|y|$ 中 `1` 的个数）。

## 高频核心二：补码一位乘法（Booth 算法）

**核心思想**：符号位**直接参与运算**，无需单独处理符号。

为什么每次看乘数末两位 $(y_i, y_{i+1})$ 就能决定操作？本质上是对补码中连续 `1` 串的等价改写：

$$
2^k + 2^{k-1} + \dots + 2^j = 2^{k+1} - 2^j
$$

将连续的 `1` 拆解为“遇到 `0→1` 跳变时减一次 $X$、遇到 `1→0` 跳变时加一次 $X$”，从而导出判定规则 $y_{i+1} - y_i$：

| 末两位 $(y_i, y_{i+1})$ | 含义（从右向左扫） | 执行操作 |
| :---: | :--- | :--- |
| **`00` / `11`** | 处于连续 `0` 或连续 `1` 内部 | `ACC + 0` |
| **`01`** | 刚走出一段 `1` 串（$1 \to 0$） | `ACC + [x]补` |
| **`10`** | 刚进入一段 `1` 串（$0 \to 1$） | `ACC + [-x]补` |

**必须牢记的执行细节**：
- `MQ` 右侧增加附加位 $y_{n+1}$，初值为 **`0`**；
- 前 $n$ 步：**判定 → 加减 → 联合算术右移 1 位**；
- 第 $n+1$ 步（针对符号位 $y_0$ 与当前 $y_{n+1}$）：**只加减、严禁再移位**！因此 $n$ 位数值位共做 **$n+1$ 次判断/加减**，**$n$ 次算术右移**。

## 中低频核心：原码加减交替除法（不恢复余数法）

**核心思想**：商的符号位同样独立异或（$Q_f = x_f \oplus y_f$），数值位按 $|x| \div |y|$ 运算（定点小数要求 $|x| < |y|$ 以防商溢出）。

传统的“恢复余数法”在减 $|y|$ 出现负余数时需加回 $|y|$ 再左移减 $|y|$，即 $2(R + |y|) - |y| = 2R + |y|$。**加减交替法**利用这一等价式消除恢复步骤：

1. **初始试减**：`ACC ← |x| - |y|`；若结果 $\ge 0$ 则发生商溢出（定点小数无法表示），正常情况应 $< 0$，上商 $q_0 = 0$。
2. **迭代 $n$ 步**：
   - 若上次余数 **$\ge 0$**：上商 **`1`**，联合**逻辑左移 1 位**，再执行 **`- |y|`**；
   - 若上次余数 **$< 0$**：上商 **`0`**，联合**逻辑左移 1 位**，再执行 **`+ |y|`**。
3. **末步恢复**：第 $n+1$ 步只判别余数正负并写入最后一位商 $q_n$（不再左移）。若此时最终余数为负，需**补加一次 `+|y|`** 恢复正余数（商不变）。

## 考前速查：五大算法对比与低频结论

在 408 真题中，**补码两位乘法**与**补码加减交替除法**极少考查完整手算，复习时重点记下表中的核心判定结论即可：

| 算法 | 408 考频 | 必须掌握的核心 | 关键细节备忘 |
| :--- | :---: | :--- | :--- |
| **原码一位乘法** | 中高频 | 根据乘数最低位决定是否相加，然后右移 | 符号单独异或；**逻辑右移** $n$ 次 |
| **补码一位乘法（Booth）** | **高频核心** | 根据末两位决定加 $X$、减 $X$ 或加 $0$ | 附加位初值 $0$；**算术右移** $n$ 次；第 $n+1$ 步不移位 |
| **补码两位乘法** | 极低频 | 每次判断 3 位，处理乘数中的 2 位 | 需提前求 $\pm 2[x]_\text{补}$ 并用 3 位符号位；算术右移 2 位 |
| **原码加减交替除法** | 中低频 | 看余数正负，决定上商和下一步加减 | **逻辑左移** $n$ 次；最终余数为负需加 $|y|$ 恢复 |
| **补码加减交替除法** | 极低频 | 看余数与除数是否同号，决定上商 | 同号上商 1 减除数、异号上商 0 加除数；末位商恒置 1 |

> **系统级延伸提示**：硬件实现整数乘除后，高级语言（如 C 语言）还会涉及定长截断下的无符号/带符号乘法溢出判定，以及负数除以 $2^k$ 时算术右移（向负无穷取整）与 C 语义（向零取整）的偏置修正——这部分结合机器指令一起考察的内容将在 <TopicLink id="408/co/machine-code-and-stack" /> 中展开。
